FOX OS Chromebook Companion v0.3

GitHub web upload:
1. Upload the root files individually.
2. Create .github/workflows/build-foxos-companion.yml using the included
   GITHUB_WORKFLOW_build-foxos-companion.yml contents.
3. In Settings > Pages, set Source to GitHub Actions.
4. Run the workflow.
5. Open the GitHub Pages URL in Chrome.
6. Install FOX OS from Chrome when prompted.

The workflow creates the icons/ directory automatically, so you do not
need to upload folders.

Important:
- The Chromebook app is the companion/developer environment.
- FOX OS remains the BONELAB code mod.
- DLL compilation is still a prototype connection; the companion does not
  claim to compile a real BONELAB DLL yet.

FOX OS Chromebook Companion

This is the Chromebook companion/developer app for FOX OS, which remains a BONELAB code mod.

This release includes:
- User-provided FOX OS logo used for the app icon set and branding
- Installable PWA manifest
- Offline service worker
- Standalone Chromebook app window
- Projects and local project storage
- Code editor
- FOX Circuits prototype
- FOX OS simulator
- Systems/API reference
- In-app browser
- Build/log prototype
- GitHub Pages deployment workflow
- Downloadable ZIP artifact workflow

The app is intentionally designed as a traditional developer tool, not an AI-generated dashboard.

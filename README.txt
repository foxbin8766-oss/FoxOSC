FOX OS Chromebook Companion v0.8

This build expands the offline-first FOX OS companion into a broader FOX ecosystem foundation.

Included:
- FOX Core dashboard and activity center
- Appearance customization: accent, density, rounded UI, animations, wallpaper mode
- Local project manager with import/export, templates and checkpoints
- Code workspace with autosave and basic formatting
- FOX Circuits visual sandbox
- General-purpose VR Game Studio prototype
- World Builder with saved scene objects
- Memory Core with searchable/tagged memories and snapshots
- Strict-by-default Permissions Core with temporary testing override
- Device Bridge with simulated Quest endpoint and pairing flow
- Evan & Agents workspace with separate agent permissions
- Task Board
- Timeline checkpoints and project restore
- Tool Forge / modular plugin slots
- Simulator
- BONELAB integration registry for BoneLib, WristHub SDK, LabFusion and loaders
- Offline validation Build Center
- Browser, docs, command palette, notifications/history
- Full FOX backup import/export

Important:
- The Quest is simulated; no headset is required to use this build.
- Native BONELAB DLL compilation is not falsely claimed; the Build Center only validates the local workspace until a real toolchain is connected.
- FOX OS is the BONELAB/FOX ecosystem project and developer companion, not a standalone Android operating system.

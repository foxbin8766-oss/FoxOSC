FOX OS Chromebook Companion v0.3

This is the Chromebook companion/developer environment for FOX OS.
FOX OS itself remains a BONELAB code mod.

v0.3 adds:
- personal developer profile and welcome dashboard
- project manager with import/export/rename/duplicate/reset
- improved code workspace and templates
- draggable FOX Circuits prototype
- simulator test panels
- searchable systems registry
- browser bookmarks/history
- FOX Docs
- Settings with accent color and profile name
- build history and prototype validation
- command palette and keyboard shortcuts
- offline local workspace
- user's FOX OS logo/branding
